# 对账通（AutoRecon） — 卖方使用培训手册

> 版本: v1.0  
> 更新日期: 2026-04-13  
> 适用系统版本: AutoRecon v3.0+

---

## 前言

**对账通**（AutoRecon）是一套专为钢铁行业打造的线上对账系统，帮助卖方企业实现从 ERP 数据拉取、对账单生成、买方确认、电子签章到智能催收的全流程闭环管理。

### 本手册适用角色

| 角色 | 系统标识 | 能做什么 |
|------|---------|---------|
| **卖方管理员** | roleType=1 | 系统初始化、模板配置、规则设定、用户管理、印章管理等全部功能 |
| **卖方操作员** | roleType=2 | 发起对账、处理异议、跟进催收、日常对账操作 |
| **卖方财务** | roleType=3 | 付款登记、发票管理、保理融资申请、账票款匹配 |

### 学习目标

完成本手册培训后，您将能够：

1. 独立登录系统并熟悉工作台各项功能
2. 完成 ERP 对接配置和对账模板创建（管理员）
3. 独立发起手动对账、批量对账和自动对账
4. 处理买方异议并完成电子签章确认
5. 管理付款、发票，并使用账票款三单匹配功能
6. 使用智能催收和信用评分管理应收账款

### 预计学习时间

| 角色 | 建议学习章节 | 预计时间 |
|------|------------|---------|
| 管理员 | 全部章节 | 3-4 小时 |
| 操作员 | 第一、三、五、六章 | 2-3 小时 |
| 财务 | 第一、四、六章 | 1.5-2 小时 |

## 第一章：快速上手

### 1.1 登录系统

**步骤 1：打开系统网址**

在浏览器（推荐 Chrome）地址栏输入系统网址，进入登录页面。页面中央显示「自动对账系统」标题和「智能对账 · 高效协同」标语。

**步骤 2：输入账号密码**

1. 在「请输入用户名」输入框中填入管理员分配的账号
2. 在「请输入密码」输入框中填入初始密码
3. 勾选「记住我」可在下次自动填充用户名
4. 点击【登 录】按钮

**步骤 3：首次登录修改密码**

首次登录时系统会强制要求修改初始密码。新密码需要满足：
- 长度不少于 8 位
- 包含大小写字母和数字
- 不能与用户名相同

**步骤 4：协议确认**

首次登录后系统会弹出《用户服务协议》和《隐私政策》对话框，请仔细阅读后勾选同意。这是使用系统的必要步骤。

> 💡 **小贴士**：如果忘记密码，请联系您的企业管理员重置。系统不支持自助找回密码。

> ⚠️ **注意**：连续输错密码 5 次后，账号将被锁定 30 分钟。

**步骤 5：进入工作台**

登录成功后自动跳转到「工作台」页面，这是系统的首页。

表格形式展示需要处理的对账单，包含对账单号、客户名称、状态标签和操作按钮（处理/签章/催收）。点击任意一行可直接跳转到对账单详情。

## 第二章：系统初始化配置（管理员）

> ⚠️ **注意**：本章内容仅限**卖方管理员**（roleType=1）操作。操作员和财务角色无权访问这些设置页面。

### 2.1 企业信息完善

**路径：系统设置 → 企业信息**

首次使用系统，管理员需要完善企业基本信息：

1. 点击左侧菜单【系统设置】→【企业信息】
2. 填写以下必填信息：
   - 企业名称（与营业执照一致）
   - 统一社会信用代码
   - 联系人姓名和手机号
   - 企业地址
3. 上传营业执照扫描件
4. 点击【保存】

> ⚠️ **注意**：企业名称一旦认证通过后不可自行修改，如需变更请联系客服。

### 2.2 ERP 对接配置

**路径：系统设置 → ERP 配置**

ERP 对接是系统自动拉取交易数据的基础，也是提升对账效率的关键步骤。

#### 4 种对接模式说明

| 模式 | 适用场景 | 技术要求 |
|------|---------|---------|
| **REST API** | ERP 系统提供标准 REST 接口 | 需要 ERP 方提供 API 文档和密钥 |
| **数据库直连** | 允许直接访问 ERP 数据库 | 需要数据库连接信息和只读账号 |
| **WebService** | ERP 使用 SOAP/WebService 接口 | 需要 WSDL 地址和认证信息 |
| **文件导入** | ERP 支持导出文件但无 API | 定期从 ERP 导出 Excel/CSV 上传 |

#### 添加 ERP 连接

1. 点击页面右上角【添加连接】按钮
2. 在弹出对话框中填写：
   - **连接名称**：便于识别的名称，如"金蝶 ERP-生产系统"
   - **连接类型**：选择 REST API / WebService / 数据库直连 / 文件上传
   - **地址**：根据类型填写 API 地址 / WSDL 地址 / 数据库连接串
   - **认证方式**：选择 API Key / OAuth2 / 用户名密码 / 证书
   - **认证配置**：JSON 格式，如 `{"apiKey":"your-key-here"}`
   - **字段映射**：JSON 格式，将 ERP 字段映射到系统字段
   - **拉取策略**：实时 / 定时 / 手动
3. 点击【确定】保存

#### 连接测试

配置完成后必须进行连接测试：

1. 在 ERP 配置列表中找到刚创建的连接
2. 点击【测试连接】按钮
3. 等待测试结果：
   - 绿色圆点 = 连接正常
   - 红色圆点 = 连接失败，请检查配置

> 💡 **小贴士**：如果选择「定时」拉取策略，可以设置 Cron 表达式，如 `0 0 2 * * ?` 表示每天凌晨 2 点自动拉取数据。

> ⚠️ **注意**：数据库直连模式请务必使用**只读账号**，避免误操作影响 ERP 数据。

#### 字段映射

字段映射告诉系统如何将 ERP 中的字段名对应到对账系统的标准字段。常用映射示例：

```json
{
  "contractNo": "合同编号",
  "orderNo": "销售订单号",
  "deliveryNo": "发货通知单号",
  "productName": "物料名称",
  "spec": "规格型号",
  "material": "材质",
  "quantity": "发货数量",
  "weight": "发货重量",
  "unitPrice": "结算单价"
}
```

### 2.3 对账模板管理

**路径：模板管理**

对账模板决定了对账单的字段、布局和展示样式。

#### 创建模板

1. 进入【模板管理】页面
2. 点击【新建模板】
3. 填写模板基本信息：
   - 模板名称（如"标准钢材对账模板"）
   - 模板描述
4. 选择模板包含的字段：合同号、订单号、发货单号、品名、规格、材质、数量、重量(吨)、单价、金额
5. 设置字段显示顺序和宽度
6. 点击【预览】查看效果
7. 确认无误后点击【保存】

#### 设置字段

每个字段可以配置以下属性：
- **是否必填**：勾选后该字段在创建对账单时为必填
- **显示名称**：可自定义列标题（如将"spec"显示为"规格型号"）
- **列宽度**：设置在表格中的显示宽度
- **对齐方式**：左对齐 / 居中 / 右对齐（金额类建议右对齐）

> 💡 **小贴士**：建议创建 2-3 套模板以适应不同场景——标准模板用于日常对账，简化模板用于小额快速对账。

### 2.4 对账规则配置

**路径：系统设置 → 对账规则**

#### 匹配规则

设置系统自动比对时的匹配逻辑：

1. **主键匹配**：选择哪些字段作为匹配依据（如合同号 + 发货单号）
2. **匹配策略**：精确匹配 / 模糊匹配
3. **匹配优先级**：当多条记录匹配时的优先规则

#### 容差设置

**路径：系统设置 → 容差优化**

由于钢铁行业发货重量和实际到货重量存在合理偏差，系统支持设置容差范围：

- **重量容差**：例如设为 0.5%，则卖方发货 100 吨，买方收货 99.6 吨视为匹配
- **金额容差**：例如设为 50 元，则金额差异在 50 元以内视为匹配

#### 自动容差学习

系统会根据历史比对数据智能推荐容差值。在【容差优化】页面可以看到：

| 列 | 说明 |
|----|------|
| 维度 | 容差维度（重量/金额等） |
| 当前值 | 当前设定的容差值 |
| 建议值 | 系统根据历史数据推荐的新值 |
| 匹配率提升 | 采纳建议后预计提升的匹配率百分比 |
| 样本数 | 推荐依据的数据样本量 |
| 置信度 | 推荐的可信程度 |

操作方式：
- 点击【采纳】：接受建议并自动更新规则
- 点击【拒绝】：忽略此条建议

> 💡 **小贴士**：建议在系统运行 1 个月后再查看容差建议，此时积累的数据量才足以给出可靠的推荐。

### 2.5 超时确认规则

**路径：系统设置 → 超时确认规则**

超时确认规则是指对账单发送给买方后，如果买方在规定时间内未做任何操作，系统将自动视为确认。

#### 全局默认天数

| 配置项 | 范围 | 说明 |
|-------|------|------|
| 无差异确认时效 | 1-7 天 | 买方收到无差异对账单后的自动确认时效 |
| 品规变更确认时效 | 12-72 小时 | 涉及品规变更的确认时效 |
| 数量超差确认时效 | 24-72 小时 | 数量存在差异的确认时效 |
| 结算单确认时效 | 1-7 天 | 结算单的自动确认时效 |
| 到期前提醒 | 1-48 小时前 | 自动确认前多久发送提醒 |

设置步骤：
1. 调整各项时效的数字
2. 点击【保存全局配置】

#### 按客户自定义

对于特殊客户，可以单独配置不同的时效：

1. 点击【新增客户配置】
2. 输入客户名称和买方企业 ID
3. 分别设置各项时效
4. 点击【确定】

#### 法律效力说明

> ⚠️ **注意**：超时自动确认具有法律效力，前提是在双方签订的合作协议中已约定此条款。系统会在到期前多次发送提醒通知，确保买方知情。

### 2.6 印章管理

**路径：签章管理 → 印章管理**

#### 企业电子章初始化

1. 进入【印章管理】页面
2. 点击【初始化企业印章】
3. 上传所需材料：
   - 企业营业执照
   - 法人身份证正反面
   - 法人授权书（如管理员非法人本人）
4. 完成法人人脸认证或短信验证
5. 等待审核（通常 1-2 个工作日）
6. 审核通过后即可使用电子印章

#### 操作员授权

管理员可以授权特定操作员使用企业印章：

1. 在印章管理页面找到已创建的印章
2. 点击【授权管理】
3. 选择需要授权的操作员
4. 设置授权范围（全部对账单 / 指定金额以下）
5. 点击【确认授权】

> ⚠️ **注意**：电子签章具有与纸质盖章同等的法律效力（依据《电子签名法》第十四条），请谨慎管理授权。

4. 点击【确定】完成创建

#### 角色权限说明

### 2.8 买方配置

**路径：系统设置 → 买方配置**

#### 添加买方企业

1. 点击【添加买方】
2. 填写买方企业信息：
   - 企业名称
   - 联系人姓名
   - 联系电话
   - 邮箱
3. 点击【保存】

#### 设置买方对账模式

根据买方的信息化程度，选择最合适的对账模式：

| 模式 | 适用买方 | 说明 |
|------|---------|------|
| ERP 自动比对 | 有完整 ERP 系统的大中型企业 | 系统自动拉取双方数据比对 |
| Excel 上传比对 | 有电子台账的中小型企业 | 买方上传 Excel 由系统自动比对 |
| 在线填写 | 无电子数据的小微企业 | 买方在平台上逐行核对 |
| OCR 识别 | 仅有纸质单据的企业 | 买方拍照上传，OCR 识别后比对 |
| 移动端确认 | 不常用电脑的企业 | 通过手机 H5 页面确认 |

### 2.9 通知模板配置

**路径：系统设置 → 通知模板**

配置发送给买方的通知内容模板，支持以下通知渠道：

- **企业微信/钉钉**：卡片式消息推送

每种通知模板均支持变量替换，如 `{买方名称}`、`{对账周期}`、`{金额}` 等。

### 2.10 提醒订阅设置

**路径：自动化 → 提醒订阅**

- 收到新的付款
- 催收计划到期提醒

可以选择通知方式（站内信 / 短信 / 邮件）以及接收频率（实时 / 每日汇总）。

## 第三章：日常对账操作

### 3.1 发起对账（手动）

**路径：对账管理 → 发起对账**

这是日常使用最频繁的功能。系统采用分步向导（4 步）引导您完成对账单创建。

#### 步骤 1：选择买方与对账周期

页面顶部的步骤条显示当前处于第 1 步「选择客户与周期」。

1. **买方企业**：在下拉框中选择或搜索买方企业名称
2. **对账周期**：选择日期范围，如 2026-03-01 至 2026-03-31
3. **对账模板**：选择已创建的模板（系统会自动选中默认模板）
4. **数据来源**：
   - **ERP 自动拉取**：系统自动从 ERP 拉取对应周期内与该买方的交易数据
   - **手动导入 Excel**：从本地上传 Excel 文件
5. **付款抵扣策略**：
   - **FIFO**（先进先出）：按交易时间顺序自动抵扣，推荐使用
   - **指定抵扣**：手动指定每笔付款抵扣哪些交易
   - **按比例**：按各笔交易金额占比均摊抵扣

填写完毕后点击【下一步】。

> 💡 **小贴士**：如果选择「ERP 自动拉取」，数据会在几秒内自动填充到下一步的明细表中。

#### 步骤 2：核对对账明细

页面进入第 2 步「对账明细」，展示一个可编辑的表格。

表格列包含：合同号、订单号、发货单号、品名、规格、材质、数量、重量(吨)、单价、金额。

可执行的操作：

- **添加行**：点击表格上方的【添加行】按钮手动增加明细
- **导入 Excel**：点击【导入 Excel】按钮从文件批量导入
  - 上传后会弹出「列映射」对话框
  - 将 Excel 的列标题与系统字段逐一对应
  - 点击【确定导入】，系统自动解析并填充数据
- **删除行**：点击行末尾的【删除】按钮移除该行
- **编辑数据**：直接在表格单元格中修改数值

表格下方显示合计栏：合计数量、合计重量、合计金额。

核对无误后点击【下一步】。

> ⚠️ **注意**：Excel 文件大小不能超过 10MB。支持 .xlsx、.xls、.csv 格式。

#### 步骤 3：预览对账单

第 3 步「预览确认」展示对账单的完整摘要：

- 买方企业名称
- 对账周期
- 使用的模板
- 数据来源
- 付款抵扣策略
- 合计金额

下方展示完整的明细表格（只读）。

最后选择发送方式：
- **生成后自动发送**：创建后立即推送给买方
- **人工确认后发送**：创建后暂存，由您手动触发发送

确认无误后点击【创建】。

#### 步骤 4：完成

创建成功后显示成功页面，包含对账单号。

可以选择：
- 【查看对账单】：跳转到该对账单详情
- 【继续创建】：清空表单创建下一个
- 【返回列表】：回到对账单列表

> 💡 **小贴士**：如果对多个买方的对账内容相似（如同一批钢材不同收货方），可以连续创建，节省时间。

#### 常见问题 FAQ

**Q：ERP 拉取数据为空怎么办？**  
A：请检查以下几点：① ERP 连接是否正常（系统设置 → ERP 配置 → 测试连接）；② 对账周期是否正确；③ 买方企业名称是否与 ERP 中一致。

**Q：Excel 导入后数据对不上怎么办？**  
A：可能是列映射不正确。重新点击【导入 Excel】，在列映射对话框中仔细核对每个字段的对应关系。

**Q：金额精度问题如何处理？**  
A：系统金额精确到小数点后 2 位，单价精确到 4 位。导入数据时请确保精度一致。

| 已签章 | 绿色 | 双方已完成电子签章 | 下载 PDF、催收 |
| 催收中 | 橙色 | 正在催收回款 | 记录回款 |

### 3.6 电子签章

#### 签章流程

1. 对账单状态为「待签章」时，在待签章列表中找到该单据
2. 点击【签章】按钮
3. 选择要使用的企业印章
4. 完成身份验证：
   - **短信验证码**：手机收到验证码并输入
   - **人脸识别**：移动端可使用人脸识别验证
5. 确认签章位置（系统会自动定位到合适位置）
6. 点击【确认签章】

#### 签章后的法律效力

电子签章基于《电子签名法》第十四条，与纸质签章具有同等法律效力。签章后的 PDF 文件：

- 嵌入数字证书，任何篡改都会被检测到
- 包含签署时间戳，可作为时间证据
- 第三方存证，支持在诉讼中出具签署报告

1. 进入对账单详情
2. 点击【下载签章 PDF】
3. 文件包含完整的对账明细和双方电子签章

## 第四章：财务管理

### 4.1 付款管理

**路径：财务管理 → 付款管理**

#### 记录买方付款

1. 进入付款管理页面
2. 点击【录入付款】
3. 填写付款信息：
   - 付款方（买方企业）
   - 付款日期
   - 付款金额
   - 付款方式：银行转账 / 承兑汇票 / 现金 / 其他
   - 银行流水号
   - 备注
4. 点击【保存】

#### 3 种分配策略

录入付款后，需要将付款分配到具体的对账单（抵扣应收款）：

**策略一：先进先出（FIFO）**
- 系统按交易发生时间自动抵扣
- 先付的款抵扣最早的应收
- 适合大多数场景，推荐使用

**策略二：指定抵扣**
- 手动选择要抵扣的对账单和具体明细行
- 一笔付款可拆分抵扣多笔交易
- 适合买方明确指定了付款用途的场景

**策略三：按比例**
- 按各笔应收金额的比例均摊抵扣
- 适合无法明确对应的预付款场景

#### 付款状态查看

| 状态 | 说明 |
|------|------|
| 待分配 | 付款已录入但尚未抵扣到对账单 |
| 部分分配 | 部分金额已抵扣 |
| 已全部分配 | 所有金额均已抵扣完毕 |

### 4.3 催收管理

**路径：财务管理 → 催收管理**

催收管理页面顶部显示三个关键统计卡：
- **活跃催收数**：当前正在催收的对账单数量
- **本月回款额**：本月已收回的款项
- **逾期总额**：所有逾期未付的总金额

#### 智能催收评分（6 维模型 A-E 级）

系统对每个买方计算催收评分，评分维度包括：

| 维度 | 权重 | 说明 |
|------|------|------|
| 付款及时性 | 高 | 历史付款是否按时 |
| 逾期频率 | 高 | 逾期次数占比 |
| 异议频率 | 中 | 提出异议的频率 |
| 合作年限 | 中 | 合作时间长短 |
| 交易规模 | 低 | 年度交易金额 |
| 行业趋势 | 低 | 行业景气度 |

评分等级从 A 到 E：

| 等级 | 分数范围 | 催收建议 |
|------|---------|---------|
| A 级 | 90-100 | 无需催收，自动付款 |
| B 级 | 75-89 | 温和提醒即可 |
| C 级 | 60-74 | 定期跟进催收 |
| D 级 | 40-59 | 加强催收力度 |
| E 级 | 0-39 | 高风险，建议法务介入 |

#### 催收操作

1. 在催收列表中找到目标对账单
2. 查看信息：应收金额、已收金额、剩余金额、到期日、逾期天数、当前阶段
3. 可执行操作：
   - 【查看日志】：查看历史催收记录
   - 【执行催收】：发送催收通知
   - 【记录回款】：录入收到的付款
   - 【暂停】：暂停催收计划
   - 【完成】：标记催收已结束

### 5.1 比对结果分析

**路径：对账管理 → 比对引擎**

比对引擎是系统的核心能力之一，用于自动对比卖方数据和买方数据的差异。

#### 比对结果概览

页面顶部展示 5 个统计卡：

| 统计项 | 说明 |
|-------|------|
| 匹配 ✓ | 完全匹配的明细行数 |
| 差异 ⚠ | 存在差异的明细行数 |
| 卖方多出 ← | 卖方有但买方没有的行 |
| 买方多出 → | 买方有但卖方没有的行 |
| 匹配率 | 匹配数 / 总行数 × 100% |

可通过标签页切换查看：全部 / 仅差异 / 卖方多出 / 买方多出。

#### 重量差异归因（7 种归因规则）

钢铁行业中重量差异是最常见的差异类型。系统提供 7 种自动归因规则：

| 序号 | 归因规则 | 说明 |
|------|---------|------|
| 1 | 磅差 | 发货磅与收货磅的正常误差 |
| 2 | 途耗 | 运输过程中的正常损耗 |
| 3 | 切割损耗 | 加工切割产生的重量损失 |
| 4 | 理计与实计差异 | 理论计重与过磅实计的差异 |
| 5 | 含水/含杂 | 原料含水含杂导致的重量差异 |
| 6 | 计量器具误差 | 不同磅秤之间的系统性误差 |
| 7 | 其他 | 无法归类的差异 |

系统会根据差异大小、历史模式自动推荐最可能的归因类型。

#### 异议预测

系统基于历史数据和机器学习模型，在对账单发出前预测买方可能提出异议的概率。预测结果可帮助您提前准备解释材料。

## 第六章：常见问题与故障排除

### 6.1 登录问题

**Q：输入正确的账号密码但登录失败**  
A：请检查以下几点：
1. 确认是否使用了正确的系统网址
2. 检查账号是否有多余空格
3. 注意密码区分大小写
4. 账号可能被锁定（连续 5 次错误后锁定 30 分钟）

**Q：登录后页面空白**  
A：尝试以下操作：
1. 清除浏览器缓存（Ctrl+Shift+Delete）
2. 使用 Chrome 浏览器最新版本
3. 关闭浏览器插件（如广告拦截器可能影响页面加载）

**Q：登录页面打不开**  
A：可能原因：
1. 网络问题，检查是否能访问外部网站
2. 系统维护中，通常会提前通知
3. 公司防火墙限制，联系 IT 部门放行

### 6.2 数据问题

**Q：ERP 拉取的数据不完整**  
A：排查步骤：
1. 确认 ERP 连接状态正常（绿色圆点）
2. 检查 ERP 字段映射配置是否正确
3. 确认对账周期是否覆盖了所有交易日期
4. 联系 ERP 管理员确认数据是否已正常入库

**Q：Excel 导入失败**  
A：常见原因：
1. 文件格式错误——仅支持 .xlsx、.xls、.csv
2. 文件超过 10MB 大小限制
3. Excel 中有合并单元格（请先取消合并）
4. 数据中包含特殊字符

**Q：对账单金额与 ERP 对不上**  
A：检查以下几点：
1. 是否有已删除或红冲的单据被计入
2. 单价精度是否一致（系统保留 4 位小数）
3. 是否包含了税金差异
4. 对账周期的起止时间是否精确

### 6.3 签章问题

**Q：签章时提示「未完成企业认证」**  
A：管理员需要先在「印章管理」中完成企业认证（上传营业执照、法人身份证等），审核通过后才能签章。

**Q：签章时人脸识别失败**  
A：建议：
1. 确保光线充足，面部无遮挡
2. 摘下帽子、口罩和墨镜
3. 如多次失败，可切换为短信验证码方式

**Q：签章后的 PDF 验证失败**  
A：PDF 文件可能被修改过。请重新从系统下载原始签章 PDF。签章 PDF 不可使用其他工具编辑。

### 6.4 通知问题

**Q：买方说没收到短信通知**  
A：排查步骤：
1. 确认买方手机号是否正确
2. 买方手机是否设置了短信拦截
3. 检查「通知模板」配置是否启用了短信通道
4. 联系客服查看通知发送日志

**Q：我自己没收到提醒通知**  
A：请检查：
1. 「提醒订阅」是否已开启对应事件的通知
2. 通知方式是否正确（站内信/短信/邮件）
3. 邮箱地址是否正确（邮件通知可能进入垃圾箱）

### 6.5 性能问题

**Q：页面加载缓慢**  
A：建议：
1. 使用 Chrome 浏览器最新版
2. 关闭不必要的浏览器标签页
3. 检查网络带宽是否充足
4. 清除浏览器缓存后重试

**Q：对账单列表搜索很慢**  
A：如果数据量很大：
1. 尽量使用筛选条件缩小范围
2. 避免使用过于模糊的搜索关键词
3. 按状态分类查看，而非查看全部

**Q：导出 PDF 时间很长**  
A：对账明细较多（>100 行）时 PDF 生成需要时间，系统在后台异步处理。生成完成后会通知您，请耐心等待。
