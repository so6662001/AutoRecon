# 提货通 — 买方使用培训手册

> **版本**：v1.0 | **最后更新**：2026 年 4 月
>
> **适用对象**：通过提货通接收提货通知、查看提货信息、确认结算的买方用户（客户）

---

## 前言

### 什么是提货通？

**提货通**是一套在线提货管理系统。一句话概括：

> 您的供应商通过提货通管理发货流程，您可以随时在手机上查看提货进度和结算信息。

您不需要安装任何 APP —— 收到通知后，在手机浏览器或微信中打开链接即可使用。买方使用 **完全免费**，无需付费或购买会员。

### 预计学习时间

本手册预计阅读时间约 **15 分钟**。如果您只需要查看提货通知并确认，只需阅读第一章（约 5 分钟）即可完成日常操作。

### 本手册结构

| 章节 | 内容概述 | 建议阅读人群 |
|------|---------|------------|
| 第一章 | 收到提货通知（免注册） | 所有用户必读 |
| 第二章 | 注册账号（可选） | 有频繁使用需求的用户 |
| 第三章 | 登录后使用 | 已注册用户 |
| 第四章 | 在线签约 | 需要在线签约的用户 |
| 第五章 | 派车管理 | 需要自行安排提货车辆的用户 |
| 第六章 | 常见问题 | 遇到问题时查阅 |

## 第一章：收到提货通知（免注册使用）

这是最常见的使用场景。当供应商为您发货后，系统会自动向您发送提货通知。**您无需注册账号**，只需按以下步骤操作即可。

### 1.1 通知方式

提货通会通过以下方式通知您：

**短信通知**

您的手机会收到一条包含提货信息的短信，格式类似：

```
【提货通】尊敬的客户，XX公司已为您安排发货，
提货单号：PO20260413001，货物：螺纹钢 HRB400，
总重量：25.380吨，请点击链接查看详情：
https://pe.example.com/g/xxxxx
```

**微信通知**

如果您已关注供应商的公众号或小程序，也可能在微信中收到通知消息，点击消息卡片即可查看详情。

💡 **提示**：通知中的链接直接点击即可查看提货详情，无需下载任何应用。

### 1.2 打开链接

1. 点击短信或微信通知中的 **蓝色链接**
2. 系统会自动在手机浏览器（或微信内置浏览器）中打开提货详情页面
3. 页面会显示一个简洁的提货信息摘要

⚠️ **注意**：请确认链接来自提货通官方域名（pe.example.com），不要打开不明来源的链接。

💡 **提示**：如果链接无法点击，您可以长按链接文字，选择「复制」，然后粘贴到手机浏览器地址栏中打开。

### 1.3 手机验证

为了确保信息安全，系统会要求您进行简单的手机验证：

1. 页面会显示 **「请输入手机号」** 输入框
2. 输入您在供应商处登记的手机号码
3. 点击 **「获取验证码」** 按钮
4. 您的手机会收到一条 6 位数验证码短信
5. 在页面上输入验证码
6. 点击 **「验证」** 按钮

💡 **提示**：验证码有效期为 5 分钟。如果没有收到验证码，请等待 60 秒后点击「重新获取」。

⚠️ **注意**：请确保输入的手机号与您在供应商处预留的手机号一致，否则无法通过验证。如果手机号已变更，请联系您的业务员更新。

### 1.4 查看提货信息

通过验证后，您将看到完整的提货信息页面。页面包含以下内容：

#### 提货摘要

页面顶部会显示提货概况：

| 信息项 | 说明 | 示例 |
|--------|------|------|
| 提货单号 | 本次提货的唯一编号 | PO20260413001 |
| 合同编号 | 对应的销售合同编号 | HT-2026-0088 |
| 供应商 | 发货方名称 | XX钢铁有限公司 |
| 货物名称 | 货物品名 | 螺纹钢 HRB400 |
| 总件数 | 本次发货的总件数 | 12 件 |
| 总重量 | 本次发货的总重量（吨） | 25.380 吨 |
| 总金额 | 本次发货的总金额 | ¥101,520.00 |
| 仓库名称 | 发货仓库 | 南京江北库 |

#### 发货明细（逐吊数据）

提货摘要下方是详细的发货明细列表。每一吊（每次吊装）的数据包括：

- **吊次编号**：第 1 吊、第 2 吊、第 3 吊……
- **品名规格**：货物名称和规格，如「螺纹钢 Φ20×12000」
- **件数**：本吊装载件数
- **理论重量**：根据规格计算的理论重量
- **实际重量**：过磅后的实际重量
- **炉号/批号**：钢材的生产批次信息

💡 **提示**：您可以左右滑动表格查看完整信息。点击任意一行可以展开查看该吊的详细数据。

#### 现场照片

系统会展示提货过程中拍摄的现场照片，通常包括：

- **车牌照片**：提货车辆的车牌号照片
- **装载照片**：货物装车后的照片
- **过磅照片**：过磅称重时的照片（如有）

点击任意照片可以放大查看。照片均带有拍摄时间水印，确保真实可信。

#### 结算信息

页面底部展示本次提货的结算信息：

| 信息项 | 说明 |
|--------|------|
| 货物总重量 | 实际过磅重量 |
| 货物总金额 | 按合同单价计算的金额 |
| 税额 | 增值税金额 |
| 含税总额 | 金额 + 税额 |
| 预付款抵扣 | 已抵扣的预付款金额 |
| 应收金额 | 本次实际应收金额 |

### 1.5 确认提货信息

查看完提货信息后，您需要进行确认操作。

**确认操作步骤**：

1. 仔细核对提货摘要、发货明细、照片和结算信息
2. 如果信息无误，点击页面底部的绿色 **「信息无误，确认提货」** 按钮
3. 系统会弹出确认对话框，再次确认您的操作
4. 点击 **「确认」** 完成操作

**确认后的效果**：

- 供应商会收到您已确认的通知
- 提货单状态变为「已确认」
- 结算流程自动推进
- 确认记录将作为交易凭证保存

💡 **提示**：确认操作不可撤销。请仔细核对信息后再点击确认按钮。

⚠️ **注意**：确认提货信息即表示您认可本次提货的货物、数量、重量及结算金额。如有任何疑问，请先联系业务员核实后再确认。

### 1.6 有问题怎么办

#### 联系业务员

如果您发现提货信息有误或有任何疑问：

1. 点击页面上方的 **「联系业务员」** 按钮
2. 系统会显示您的业务员姓名和联系电话
3. 您可以直接拨打电话或发送短信沟通
4. 与业务员确认后，供应商会在系统中修改相关信息
5. 修改完成后，您会收到新的确认通知

💡 **提示**：发现问题时，请尽快联系业务员，不要直接点击确认按钮。

#### 不确认会怎样（超时自动确认）

如果您在规定时间内没有进行任何操作：

- 系统默认设置为 **48 小时** 超时自动确认（具体时间以供应商设置为准）
- 超时后，系统会自动将提货状态变更为「已确认」
- 自动确认前，系统会再次发送提醒短信

⚠️ **注意**：自动确认与手动确认具有同等效力。如果有异议，请务必在超时前联系业务员处理。

## 第二章：注册账号（可选）

如果您与供应商有长期合作关系，注册一个账号可以让您更方便地管理所有提货记录。

### 2.1 注册的好处

注册账号后，您可以获得以下额外功能：

| 功能 | 未注册 | 已注册 |
|------|--------|--------|
| 查看单次提货通知 | ✅ | ✅ |
| 查看历史提货记录 | ❌ | ✅ |
| 查看合同信息 | ❌ | ✅ |
| 在线签约 | ❌ | ✅ |
| 结算对账 | ❌ | ✅ |
| 证据包查看 | ❌ | ✅ |
| 自行派车 | ❌ | ✅ |
| 工作台概览 | ❌ | ✅ |

💡 **提示**：如果您每月有多次提货，强烈建议您注册账号，方便随时查看历史记录和结算信息。

### 2.2 注册流程

注册流程非常简单，只需 2 分钟即可完成：

1. 打开提货通知链接后，点击页面上方的 **「注册/登录」** 按钮
2. 输入您的手机号码（请使用供应商处预留的手机号）
3. 点击 **「获取验证码」**
4. 输入收到的 6 位验证码
5. 设置登录密码（至少 8 位，包含数字和字母）
6. 填写您的公司名称和联系人姓名
7. 点击 **「完成注册」**

注册完成后，系统会自动关联您在供应商处的合同和提货记录。

💡 **提示**：注册后可在微信中收藏登录页面，方便下次快速访问。每个手机号只能注册一个账号，如提示已注册请尝试直接登录。

## 第三章：登录后使用

注册并登录后，您将进入买方工作台，可以全面管理您的提货信息。

### 3.1 工作台

登录后，首先看到的是 **工作台** 页面，这是您的信息中心：

**工作台包含以下模块**：

1. **待处理事项**
   - 待确认的提货单数量（红色角标提醒）
   - 待签约的合同数量
   - 待确认的结算单数量

2. **最近提货**
   - 展示最近 5 笔提货记录
   - 点击可查看详情

3. **快捷入口**
   - 合同列表
   - 提货记录
   - 结算记录
   - 派车管理

💡 **提示**：工作台上的红色数字角标表示有待处理的事项，请及时处理以免影响业务流程。

### 3.2 合同查看

#### 查看与供应商的合同

1. 在工作台点击 **「合同列表」**，或点击底部导航栏的 **「合同」** 标签
2. 页面显示所有与供应商签订的合同列表
3. 每份合同会展示以下概要信息：
   - 合同编号
   - 供应商名称
   - 合同总量（吨）
   - 合同总金额
   - 签约状态（未签 / 已签 / 双方已签）
   - 合同状态（执行中 / 已完成）

4. 点击任意合同可以查看详情，包括：
   - 合同基本信息
   - 货物清单（品名、规格、数量、单价）
   - 付款条件
   - 交货期限
   - 指定仓库

#### 合同进度

在合同详情页中，您可以看到直观的进度展示：

```
合同总量    ████████████████████░░░░  80%
已提货量    ████████████████░░░░░░░░  64%
已结算      ████████████░░░░░░░░░░░░  48%
已付款      ████████░░░░░░░░░░░░░░░░  32%
```

- **合同总量**：合同约定的总重量
- **已提货量**：已完成提货的重量
- **已结算**：已完成结算的金额
- **已付款**：已实际支付的金额

💡 **提示**：通过进度条，您可以快速了解合同的执行情况，方便安排后续采购计划。

### 3.3 提货记录查看

#### 提货单列表

1. 在工作台点击 **「提货记录」**，或点击底部导航栏的 **「提货」** 标签
2. 页面以列表形式展示所有提货记录
3. 支持以下筛选条件：
   - 时间范围（近 7 天 / 近 30 天 / 自定义）
   - 合同编号
   - 提货状态（全部 / 待确认 / 已确认 / 已结算）

4. 每条提货记录显示：
   - 提货单号
   - 合同编号
   - 货物名称
   - 总重量 / 总金额
   - 提货状态
   - 提货时间

💡 **提示**：点击列表右上角的搜索图标，可以按提货单号快速查找特定记录。

#### 提货详情

点击任意提货记录，进入详情页面。详情页包含以下信息区块：

**车辆信息**

| 信息项 | 示例 |
|--------|------|
| 车牌号 | 苏A12345 |
| 驾驶员姓名 | 张三 |
| 驾驶员电话 | 138****5678 |
| 承运公司 | XX物流有限公司 |
| 到达时间 | 2026-04-13 09:30 |

**发货明细**

与免注册查看时一致，展示每一吊的详细数据，包括品名、规格、件数、重量等。

**现场照片**

展示提货过程中拍摄的所有照片。照片按类型分组：
- 车牌照
- 装载照
- 其他照片

**确权信息**

确权是指系统验证提货人身份的过程。详情页会展示：

- 确权方式（短信验证 / 电话确认 / 人脸识别等）
- 确权结果（通过 / 未通过）
- 确权时间

**结算信息**

展示本次提货的完整结算明细，与前文描述一致。

**时间线**

页面底部展示本次提货的完整时间线，例如：

```
📋 2026-04-13 08:00  提货单创建
🚛 2026-04-13 08:30  驾驶员已分配（张三）
📍 2026-04-13 09:30  车辆到达仓库
⚖️ 2026-04-13 09:45  开始装货（第1吊）
⚖️ 2026-04-13 10:00  装货完成（第2吊）
⚖️ 2026-04-13 10:15  装货完成（第3吊）
📸 2026-04-13 10:20  现场拍照完成
✅ 2026-04-13 10:25  发货确认完成
📩 2026-04-13 10:30  通知已发送给客户
✔️ 2026-04-13 14:00  客户已确认
💰 2026-04-13 14:05  结算单已生成
```

💡 **提示**：时间线帮助您了解整个提货过程的每一个关键节点，如有争议可作为参考依据。

### 3.4 结算确认

当供应商生成结算单后，您可以在系统中查看并确认。

**结算确认步骤**：

1. 在工作台看到 **「待确认结算」** 的红色角标
2. 点击进入待确认结算列表
3. 选择要确认的结算单
4. 查看结算详情：
   - 结算单号
   - 关联提货单号
   - 货物总重量
   - 货物总金额
   - 税额
   - 含税总额
   - 预付款抵扣
   - 应收金额
5. 如结算金额无误，点击 **「确认结算」** 按钮
6. 如有异议，点击 **「提出异议」** 并填写异议说明

💡 **提示**：结算单支持下载 PDF 文件，方便您打印存档或内部审批。

⚠️ **注意**：确认结算后，相关金额将进入应收账款流程。请仔细核对后再操作。

### 3.5 证据包查看

提货通为每一笔提货生成完整的 **电子证据包**，用于记录整个交易过程的关键数据。

**证据包包含以下内容**：

| 文件 | 说明 |
|------|------|
| 合同 PDF | 签署的销售合同文件 |
| 提货单 PDF | 提货单详细信息 |
| 发货数据 | 每吊装货的详细数据 |
| 现场照片 | 所有现场拍摄的照片 |
| 签字记录 | 现场签字确认的图片 |
| 结算单 PDF | 结算明细文件 |

**查看方式**：

1. 进入提货详情页
2. 滑动到页面底部，找到 **「证据包」** 区域
3. 点击 **「查看证据包」** 按钮
4. 可逐项查看或一键下载全部文件

💡 **提示**：证据包中的数据均经过区块链存证，具有防篡改特性。每个证据包拥有唯一的哈希值（数字指纹），可用于验证数据完整性。

⚠️ **注意**：证据包内容一经生成不可修改。如果发现证据包中的信息有误，请及时联系供应商处理。

## 第四章：在线签约（订货合同）

提货通支持在线签约功能，让您无需线下签字盖章即可完成合同签署。

### 4.1 收到签约邀请

当供应商创建合同并发起签约邀请后，您会通过以下方式收到通知：

**短信通知**

```
【提货通】尊敬的客户，XX公司邀请您签署销售合同
（合同编号：HT-2026-0088），请点击链接查看并签约：
https://pe.example.com/sign/xxxxx
```

**工作台提醒**

如果您已登录，工作台会显示「待签约合同」的红色角标提示。

💡 **提示**：签约邀请通常有有效期限，请在收到通知后尽快处理。

### 4.2 查看合同内容

点击签约链接后，您可以查看完整的合同内容：

1. **合同基本信息**
   - 合同编号
   - 卖方信息（供应商公司名称、地址等）
   - 买方信息（您的公司名称、地址等）
   - 合同有效期

2. **货物清单**
   - 品名
   - 规格
   - 数量
   - 单价
   - 金额

3. **交易条款**
   - 付款方式和期限
   - 交货方式和期限
   - 质量标准
   - 违约责任

4. **附加条款**
   - 供应商可能添加的特别约定

💡 **提示**：请仔细阅读合同全部内容，特别是付款方式、交货期限和违约责任等关键条款。如有不理解的内容，请联系您的业务员解答。

⚠️ **注意**：合同一经签署即具有法律效力。请务必在充分理解合同内容的前提下进行签约操作。

### 4.3 在线签约操作

确认合同内容后，按以下步骤完成签约：

1. 阅读完合同全文后，勾选页面底部的 **「我已阅读并同意合同全部条款」** 复选框
2. 点击 **「在线签约」** 按钮
3. 系统会要求您进行身份验证（短信验证码）
4. 输入验证码后，进入签名页面
5. 在手机屏幕上用手指签写您的姓名
6. 确认签名满意后，点击 **「提交签名」**
7. 系统提示 **「签约成功」**

💡 **提示**：签名不满意可以点击「重新签名」；不同意合同内容可以点击「拒绝签约」并填写理由。

### 4.4 签约后的效果

签约成功后：

1. **合同生效**：合同状态变为「双方已签」，合同正式生效
2. **PDF 生成**：系统自动生成带有双方电子签名的合同 PDF 文件
3. **通知供应商**：供应商会收到您已签约的通知
4. **存证备案**：签约过程的所有数据将被安全存证，包括签名图片、签约时间、签约设备信息等
5. **合同可查**：签约后的合同可以在「合同列表」中随时查看和下载

💡 **提示**：签约完成后，建议您下载合同 PDF 文件保存备份。

## 第五章：派车管理

在某些合作模式下，您（买方）需要自行安排车辆到供应商仓库提货。提货通的派车管理功能可以帮助您方便地管理车辆调度。

### 5.1 客户自行派车

当合同约定由买方自行安排提货车辆时，您可以通过提货通完成派车操作。

**派车步骤**：

1. 登录提货通，进入工作台
2. 点击 **「派车管理」** 或在合同详情页点击 **「我要派车」**
3. 选择要派车的合同
4. 填写派车信息：
   - **车牌号码**：提货车辆的牌照号码（必填）
   - **驾驶员姓名**：提货驾驶员的真实姓名（必填）
   - **驾驶员电话**：驾驶员的手机号码（必填）
   - **承运公司**：物流公司名称（如有）
   - **预计到达时间**：车辆预计到达仓库的时间
5. 确认信息无误后，点击 **「提交派车」**

💡 **提示**：请确保填写的驾驶员信息准确无误。供应商仓库会根据您提供的信息验证提货人身份。

⚠️ **注意**：派车信息提交后，供应商将收到通知并为您生成提货码。请确保驾驶员收到提货码后再前往仓库。

### 5.2 指定驾驶员

您可以提前在系统中维护常用的驾驶员信息，方便每次派车时快速选择。

**添加常用驾驶员**：

1. 进入 **「派车管理」** 页面
2. 点击 **「常用驾驶员」** 标签
3. 点击 **「添加驾驶员」**
4. 填写驾驶员信息：
   - 姓名
   - 手机号码
   - 常用车牌号
   - 所属承运公司（可选）
5. 点击 **「保存」**

**派车时选择常用驾驶员**：

1. 在派车页面，点击驾驶员输入框旁的 **「选择常用」** 按钮
2. 从列表中选择驾驶员
3. 系统自动填充驾驶员姓名、手机号和车牌号
4. 确认信息后提交

💡 **提示**：建议将常合作的驾驶员提前添加到常用列表，派车时一键选择，省时省力。

### 5.3 查看派车状态

提交派车后，您可以实时跟踪派车状态。

**派车状态说明**：

| 状态 | 说明 |
|------|------|
| 已提交 | 派车信息已提交，等待供应商确认 |
| 已确认 | 供应商已确认，提货码已生成 |
| 提货码已发送 | 提货码已发送给驾驶员 |
| 车辆已到达 | 驾驶员已到达仓库 |
| 装货中 | 正在装货 |
| 已完成 | 提货完成，车辆已离开 |

**查看方式**：

1. 进入 **「派车管理」** 页面
2. 查看派车记录列表
3. 每条记录右侧显示当前状态
4. 点击可查看详细信息和时间线

💡 **提示**：当状态发生变化时，系统会自动向您发送通知，您也可以随时主动刷新查看。

## 第六章：常见问题

### 6.1 通知收不到

**问题**：提交了提货但没有收到短信或微信通知。

**可能原因及解决方法**：

1. **手机号不正确**
   - 请联系供应商确认您的预留手机号是否正确
   - 如已更换手机号，请通知供应商更新

2. **短信被拦截**
   - 检查手机的「垃圾短信」或「骚扰拦截」文件夹
   - 将提货通的短信号码添加到白名单
   - 部分手机品牌（如华为、小米）的安全中心可能会拦截通知短信

3. **手机信号问题**
   - 确认手机信号正常
   - 尝试重启手机

4. **运营商问题**
   - 极少数情况下，运营商可能延迟发送短信
   - 如等待超过 10 分钟仍未收到，请联系业务员

💡 **提示**：您也可以主动登录提货通查看是否有新的提货通知。

### 6.2 提货信息有误

**问题**：收到的提货通知中，货物名称、数量或重量与实际不符。

**处理步骤**：

1. **不要急于确认** —— 在问题解决前，请不要点击「确认」按钮
2. **联系业务员** —— 点击通知页面上的「联系业务员」获取联系方式
3. **说明问题** —— 向业务员详细说明哪些信息有误以及正确值应该是什么
4. **等待修改** —— 供应商在系统中修改后，您会收到更新后的通知
5. **确认修改后的信息** —— 检查修改后的信息是否正确，确认无误后再点击确认

⚠️ **注意**：如果超时自动确认即将触发，但问题尚未解决，请立即联系业务员申请延长确认期限。

### 6.3 结算金额有异议

**问题**：结算单中的金额与您预期的不一致。

**常见原因**：

1. **单价差异** —— 系统按合同约定单价计算，请核对合同中的单价条款
2. **重量差异** —— 结算以实际过磅重量为准，可能与理论重量有差异
3. **税率问题** —— 确认税率是否与合同约定一致
4. **预付款抵扣** —— 检查预付款抵扣金额是否正确

**处理步骤**：

1. 在结算详情页记录下有异议的具体项目和金额
2. 点击 **「提出异议」** 按钮
3. 选择异议类型并填写详细说明
4. 提交后，供应商会收到通知并进行核实
5. 核实结果会通过系统消息通知您

💡 **提示**：提出异议时请尽量提供具体的数据对比，有助于加快处理速度。

### 6.4 数据安全和隐私

**您的数据很安全**。提货通采用以下措施保护您的数据：

1. **数据加密** —— 所有数据传输采用 HTTPS 加密，敏感数据在存储时进行脱敏处理

2. **访问控制** —— 您只能查看与您相关的合同和提货记录，供应商无法查看您与其他供应商的交易数据

3. **数据存证** —— 关键交易数据经过区块链存证，不可篡改，可用于法律举证

4. **隐私保护** —— 提货通不会将您的数据分享给第三方，个人信息仅用于提货业务流程
